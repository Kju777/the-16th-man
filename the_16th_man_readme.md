# The 16th Man 🏉

The 16th Man is a mobile-first, AI-powered rugby coaching dashboard designed to give players access to top-tier coaching, scheduling, and nutrition tracking right from their pockets.

## 🌟 Features

*   **AI Coaching Staff:** Powered by Gemini AI. Get instant advice from specialized personas:
    *   **Coach Marcus (Skills):** Tactics, passing, offloading, and tackling.
    *   **Coach Jonah (S&C):** Strength & conditioning, Bronco tests, and explosive power.
    *   **Coach Lucy (Nutrition):** Macros, recovery meals, and hydration.
*   **Weekly Planner:** Keep track of pitch sessions, gym days, and active recovery.
*   **Fuel Station:** Log your daily meals, track calories, and monitor protein intake to ensure you're fueled for the pitch.
*   **Health Sync (Mock):** A dashboard ready to sync with your device's health data (steps & active calories).

## 🛠 Tech Stack

*   **Frontend:** HTML5, React 18 (via CDN), Tailwind CSS
*   **Backend / Database:** Firebase Authentication & Firestore
*   **AI Integration:** Google Gemini API

## 🚀 How to Run

1. Simply open the `index.html` file in any modern web browser.
2. Go to the **Settings** tab (the gear icon).
3. Enter your Gemini API Key to activate the AI coaches.
4. Start chatting and logging your meals!
